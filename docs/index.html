Paste from Word without losing your equations

Word puts every equation on the clipboard twice — as real maths, and as a screenshot. Every editor takes the screenshot, so the author can never fix a typo in their own formula again. wordpaste takes the maths.

          Google Docs equations cannot be recovered by anyone — Docs puts
          them on the clipboard as images already. Word is the unusual one: it
          sends the picture and the real maths, which is the gap this
          package exploits. Docs still gets the colour fix, because it writes
          color: rgb(0,0,0) inline and that turns black-on-black on
          a dark theme.
        

      


      

        
That is three lines in your editor

        
import { isWordHtml, hasWordMath, cleanWordHtml } from 'wordpaste';

const clean = isWordHtml(html) || hasWordMath(html) ? cleanWordHtml(html) : html;
